# 赛题问题（2）：BERT-Base 论文资料

本仓库供阅读赛题、代码、配置和**已完成的实验结果**，以撰写答题论文。按要求未上传附件 2/3 原始数据、训练专用 pickle、BERT 预训练权重、训练检查点和推理包。本地完整资料包保留这些文件；本仓库不能单独重训或运行推理。

## 建议阅读顺序

1. `01_赛题/赛题原文.docx`：问题（2）的要求。
2. `04_实验结果/论文分析/论文用_训练配置与消融总表.md`：训练参数及 16 行四指标消融结果。
3. `04_实验结果/论文分析/问题2_P0_P1必要实验核对.md`：113 格连续局部缺失、附件 3、错误归因的索引。
4. `04_实验结果/论文分析/三种子分支消融与测试集复核.md`：跨种子结果及测试集使用限制。
5. `04_实验结果/论文分析/bert_base_missing_grid_metrics.csv`、`validation_error_attribution_per_sample.csv` 和 `04_实验结果/附件3_30条最终预测.csv`：论文制表原始实验输出。

## 指标口径

最终选定模型是本地冻结的 BERT-Base seed 1729。服务器训练的同配置模型是独立检查点；服务器消融指标不能与本地 113 格结果写成同一次模型推理。缺失长度以对齐位置数计，附件 3 的零值统计不等于真实缺失标注。三种子测试结果属于重复访问测试集后的事后诊断，不用于选模，也不应称为新的盲测。关闭缺失增广只有一个种子，不支持跨种子稳定收益结论。
